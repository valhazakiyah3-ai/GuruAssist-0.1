# Education-platform assistance boundaries

## Safe default

Prepare information in a structured, copy-ready format for the teacher. The skill may summarize a document into fields such as title, description, subject, grade, learning objective, assessment description, modality, and method when the user asks.

## Do not assume requirements

- A platform feature being available does not mean every teacher is required to use it.
- A document not being required for upload does not mean the teacher has no planning responsibility under school policy.
- Field names, limits, accepted file types, and publication workflows can change. Verify the current official platform guide before giving exact step-by-step instructions.

## No unauthorized submission

Do not request passwords, one-time codes, session cookies, or authentication tokens. Do not bypass CAPTCHA, access controls, or platform restrictions. Do not submit or publish without explicit teacher approval. Do not claim that a submission succeeded unless the platform or authorized integration confirms it.

## Integration roadmap

A future integration must use an officially documented API or another permitted interface, comply with platform terms, protect personal data, log actions, and provide a review/approval step. Browser automation should be considered only where permitted and should never evade security controls.
