# Reusable teacher workflow

## One-time lesson record

Collect the following once and reuse it:

- School context (use a pseudonym if sharing externally).
- Education level, grade/class, phase (if applicable).
- Subject and topic/unit.
- Curriculum/framework name, version, and year.
- Official learning outcome or source excerpt.
- Lesson duration and number of meetings.
- Learner needs (aggregate, non-identifying description).
- Available resources, devices, and connectivity.
- School-required document format.
- Requested outputs.

## Suggested sequence

1. Read and summarize source documents.
2. Extract exact official learning outcomes without changing their meaning.
3. Draft measurable learning objectives.
4. Decide what evidence would show that each objective has been achieved.
5. Select activities and methods that produce that evidence.
6. Select resources and media appropriate to access and context.
7. Draft the lesson sequence and allocate time.
8. Draft formative and/or summative assessment.
9. Create worksheets and rubrics only where useful.
10. Run alignment, completeness, accessibility, and factual checks.
11. Prepare metadata or exports if requested.
12. Ask the teacher to review and approve.

## Efficiency rules

- Maintain a single source-of-truth record for shared fields.
- Reuse school identity and lesson context only with the user's permission and in a privacy-appropriate way.
- Generate only requested outputs; do not create documents just because a template exists.
- When one source field changes, identify dependent sections and update them consistently.
- Do not force the teacher to re-enter information already supplied in the current task.
- Prefer editable outputs and clearly identify draft status.
