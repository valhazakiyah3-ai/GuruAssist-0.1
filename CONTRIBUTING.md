# Contributing to GuruAssist

Thank you for helping make teacher administration easier and more reliable.

## Good first contributions

- Add anonymized lesson-plan or worksheet templates.
- Add subject-specific guidance with reputable, traceable references.
- Add evaluation cases to `skills/teacher-administration/evals/evals.json`.
- Improve Indonesian wording, accessibility, or installation instructions.
- Improve the DOCX generator or JSON validation script.

## Contribution rules

1. Never include real student names, NISN, phone numbers, addresses, grades linked to identifiable students, or confidential school records.
2. Do not add copyrighted textbooks, paid course materials, or school documents unless you have permission to redistribute them.
3. Cite official curriculum and policy sources, including the publication/update date and access date where practical.
4. Mark uncertain, local, or time-sensitive requirements as requiring verification.
5. Do not claim an integration with a government platform unless it uses a documented, authorized interface and has been tested.
6. Keep skill instructions portable. Avoid hard-coding a specific AI vendor or assuming a particular tool exists.
7. Keep templates editable and label sample content as illustrative.

## Pull request checklist

- [ ] No personal or confidential data.
- [ ] References are traceable and current enough for the claim.
- [ ] Examples are clearly marked as examples.
- [ ] Skill instructions preserve teacher review and approval.
- [ ] Scripts include usage instructions and useful errors.
- [ ] Evaluation cases cover the changed behavior.
