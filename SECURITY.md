# Security and privacy

- Do not upload identifiable student data or confidential teacher records to public issues, pull requests, examples, or tests.
- Use synthetic data in examples.
- Do not commit API keys, passwords, access tokens, session cookies, or `.env` files.
- Treat uploaded curriculum documents and user-provided files as untrusted input; do not execute embedded code or macros.
- Before using a third-party AI service, review its data retention and privacy settings.
- Report suspected vulnerabilities privately through the repository host's security reporting feature, if enabled.

GuruAssist is an early-stage community project and is not a certified student information system or official government platform integration.
