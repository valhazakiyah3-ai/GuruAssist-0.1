# Code of Conduct

GuruAssist is a collaborative project. Participants are expected to be respectful, constructive, and inclusive.

Examples of unacceptable behavior include harassment, discrimination, personal attacks, publishing private information, and deliberately misleading claims about educational policy or AI capabilities.

Project maintainers may edit, reject, or remove contributions that violate this code. For serious concerns, contact the repository maintainers through the private reporting channel configured on the hosting platform.
